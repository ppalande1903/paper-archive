Fonts embedded in downloaded PDFs (js/pdf.js). They are the site's own typefaces, as TrueType, plus two
fallbacks for characters those don't have (Greek letters, maths symbols), which are only fetched when a
paper needs them. `coverage.json` lists the characters each font has, so text can switch font per character.

|---|---|---|

| InstrumentSerif-*.ttf | Instrument Serif | SIL OFL 1.1, see OFL-instrumentserif.txt |
| IBMPlexMono-*.ttf | IBM Plex Mono | SIL OFL 1.1, see OFL-ibmplexmono.txt |
| Caveat-SemiBold.ttf | Caveat | SIL OFL 1.1, see OFL-caveat.txt |

All were downloaded from Google Fonts.
